## 2. Why it failed — and what the failure is evidence for

* **Budget, not placement, dominates the catalogue proxy.** Every C2/C3 cell spent the maximum allowed
  budget (3 x control; `budget_ratios = [3.0, 3.0, 3.0, 3.0]`), because the module's own `dti_hat`
  estimator — which scores a dot by the parent mass it covers — read 0.68-0.79 and kept climbing. The
  estimator is optimistic by ~4x against the measured masked DTI and, critically, it is blind to
  *which* parent mass is real: the extra 16,000 pixels it bought were mostly false positives on the
  catalogue-gap target (fold NW, draw 20: C0 emitted 7,397 px with FP 7,161; C2 emitted 22,191 px with
  FP 21,693 — TP rose only 485 → 726 while FP tripled).
* This is the same lesson as the live ladder: the solid H19-5 file emitted 121,131 pixels and was
  reported at 0.1922; the 44,090-pixel dotted version of the same field was reported at 0.2600. **More
  mass from the same field is not better** — the metric's FP term (0.2 weight) and, more importantly,
  the fact that the extra mass is *not* near new faults, dominate.
* **Where the coverage rule does win is exactly where the field is not the catalogue.** On the SGMC
  off-catalogue class (62,703 truth pixels at least 300 m from any supplied catalogue pixel), C2 and C3
  beat both controls by +0.047 to +0.064 in every fold, and C2 is 3.6x the control's *coverage* of that
  class (0.2057 vs 0.0968 in fold NW/draw 20). The rule spends its budget where the catalogue is absent,
  which is what the competition scores, while the control concentrates on catalogue-adjacent structure.

**Interpretation (flagged as judgement, not measurement):** the two proxies disagree because they are
different targets — hidden *catalogue* pixels are by construction near visible catalogue structure,
whereas the SGMC class is far from it. The coverage rule is a better emitter for the far-from-catalogue
regime and a worse emitter for the near-catalogue regime. Which one the private expert label set
resembles is **not known**, and this repository has no access to it. Two independent lines of evidence
point opposite ways: the sibling-reported staff statements and peer proxy calibration rank the
SGMC-style off-catalogue proxies above catalogue-hidden proxies, while this project's own H29 screen
found catalogue-hidden proxies uninformative for exactly the reason above.

## 3. What this costs and what it buys

* **Cost:** one rejected hypothesis for the *slot* decision; the C2/C3 emissions are not slot candidates
  (they fail their frozen gate and their budget is 3x the registered control), and no new submission file
  is produced from them.
* **Buys:** (a) a reproducible, negative, preregistered result for the group ledger; (b) evidence that the
  module's parent-mass `dti_hat` must never be used as a budget selector (it selects the maximum); (c) a
  *diagnostic* emitter whose behaviour on the off-catalogue class is measurable and consistent, which can
  be used as an emission rule for a *better-calibrated prior* rather than for a lineament mask; (d) a
  concrete instruction for the next screen: match budgets across arms and gate on the off-catalogue class
  as primary, with the catalogue-hidden class reported as a secondary, non-binding diagnostic.

## 4. Limitations (stated plainly)

1. Both responses are proxies. Neither is the organizer's hidden expert label set; neither is a
   competition score.
2. The SGMC off-catalogue class is a state-map inventory; some of its pixels may correspond to faults
   that the organizers consider "known" through a different mapping, and vice versa. Its relationship to
   the leaderboard is reported by peers (Spearman rho = +0.52, n = 15, p = 0.048, peer-reported,
   unverified here), not established here.
3. C2 and C3 were not budget-matched to the controls at the registered control budget; the preregistration
   allowed up to 3x, and the arm used it. A budget-matched variant was **not** run and is listed as
   remaining work rather than reported as a result.
4. The arms were tested only with the H34 screen's detector; nothing here says the emission rule would
   behave the same on a different habitat field.
