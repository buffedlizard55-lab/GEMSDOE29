# Candidate ranking — initial slate predates implementation; post-sync revision (2026-10-03)

## Scope and evidence boundary

At the branch point (`ad130c8d`), `GEMSDOE29` contained only a one-line README. This slate was drafted and H31 implemented on that branch before `main` advanced through PRs #1 and #2. Rebase review then surfaced the H29 experiment already committed on latest `main`: raw-RTP/isostatic-gravity worming, persistence as a gate/rank/head feature, and a thermal-probe arm were screened, and all four failed the frozen `+0.005` catalogue-gap proxy screen. The raw file also contains extra draws 2–3 for all arms despite those failures; they are not eligible confirmations, and the original gate snapshot has a serialization bug (see `knowledge/06_h29_gate_reconciliation_2026-10-03.md`). This update corrects the prior-work boundary; H31 is not a new worming category. It is only a narrow test of a regularized RTP-to-pseudogravity transform plus explicit lateral drift, features not in the H29 arm. H31 remains unfitted and should be lower priority than the unimplemented H32 terrain-shape test after this review.

The novelty review also inspected the public `GEMSDOE25` predecessor's feature registry, experiment registrations/results, and submission page. That predecessor had fixed-scale potential-field gradients/ridges, DEM curvature/scarp descriptors, catalogue geometry, thermal/geochemical features, score-aware thinning, generic geophysical conjunctions, single-tip continuation, and a relay-bridge × scarp experiment. Its H30-1 candidate failed fresh-draw confirmation; earlier family results were spatial catalogue-gap proxies, not competition scores. The bytes are owner mirrors, not organizer-authenticated data.

The original slate preceded any GEMSDOE29 H31 model fit; the rebase correction was made before any such fit. “Not tried” means the *specific operation* was not found in the reviewed repositories, not that no competitor has tried it. DTI ranges below are **planning brackets**, not score predictions, confidence intervals, or live leaderboard estimates. The folds simulate catalogue gaps, not the competition's expert-labelled hidden faults.

### Post-sync prioritization and H29 result

The latest main already tested raw-RTP/isostatic-gravity continuation persistence as an emission gate, a ranking term, and model features, plus a residualized thermal-feature arm. All four H29 arms failed the preregistered `+0.005` screen/confirmation catalogue-gap proxy gate; the recorded confirmation draws did not rescue an arm, and no weekly slot followed. Those results do not show that all potential-field methods fail on expert-labelled hidden faults, but they materially lower the prior for a closely related persistence variant. The post-sync ranking therefore puts H32's terrain-shape asymmetry first, retains H31 only as a specific pseudogravity-transform/drift extension, and keeps H33 blocked until its official data prerequisites are validated. H31 remains unfitted; any spatial screen must compare same-run controls and cannot justify a slot by itself. ## Source-checked scientific basis and limitations

1. **Official competition target/metric/format:** the [DrivenData problem description](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/) says labels are incomplete, the task is to predict faults, predictions are confidence values in `[0,1]`, and the distance-weighted Tversky metric uses a 300-m triangular kernel with `alpha=0.2`, `beta=0.8`. The same page specifies EPSG:32611, 100-m pixels, one float32 band, and null/NaN outside the data bounds. The data tab redirects to login in this environment; no DrivenData credentials or automated requests are used.
2. **Potential-field worm method:** Hornby, Boschetti & Horowitz (1999), [DOI 10.1046/j.1365-246x.1999.00788.x](https://doi.org/10.1046/j.1365-246x.1999.00788.x), is the primary paper. Horowitz's DOE/Stanford-hosted 2018 review, [“Potential Field Poisson Wavelet Multiscale Edge Analysis (Worms) for Geothermal”](https://pangea.stanford.edu/ERE/pdf/IGAstandard/SGW/2018/Horowitz.pdf), was read. It describes upward continuation to multiple heights, local maxima of horizontal-gradient modulus, and (for magnetic data) a pseudogravity transform. The [SEG 2014 abstract](https://library.seg.org/doi/10.1190/segam2014-1323.1) describes pseudogravity as vertical integration of a magnetic grid using FFT; the [Seequent/Oasis montaj manual](https://help.seequent.com/Oasismontaj/2023.2/Content/gxhelp/fft2con/fft2con_gpsd.htm) says the filter can start from an RTP grid when inclination is set to 90° and declination to 0°. H31 therefore derives a **regularized vertical-integration pseudogravity proxy** from the supplied RTP grid; it will not call raw RTP “pseudogravity,” and it will document its low-wavenumber regularization and the fact that it is not a vendor-exact filter. It uses the supplied isostatic gravity anomaly as a gravity proxy, not a Bouguer grid. The review also explicitly warns that potential-field inversion is non-unique, stronger off-edge sources can shadow an edge, deep edge locations become less accurate, and persistence/strength is not a direct depth proof. H31 is **worming-like**, not the full Hornby Poisson-wavelet inversion: it does not recover a validated source distribution, fault dip, or depth.
3. **Terrain evidence:** the official [USGS 3DEP products page](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services) states 3DEP products are free and without use restrictions. The [USGS 2024 fault-scarp mapping release](https://www.usgs.gov/data/quaternary-fault-mapping-zapata-and-blanca-sections-sangre-de-cristo-fault-zone-high), DOI [10.5066/P13NFGLT](https://doi.org/10.5066/P13NFGLT), documents fault-scarp/tectonic-lineation mapping from 1-m 3DEP topography and derivatives, with GPS validation at select locations. This is a methods example in Colorado, not evidence that the same profile rule identifies GeoDAWN hidden faults.
4. **Great Basin structural motivation:** Faulds & Hinz (2015), [DOE OSTI-hosted proceedings paper](https://www.osti.gov/servlets/purl/1724082), reports common structural settings among inventoried Great Basin geothermal systems, including relay ramps/step-overs, terminations and intersections. This motivates structural tests but does **not** establish the distribution of the competition's withheld fault pixels. The competition target is fault mapping, not direct geothermal-vent prediction.

## Frozen H31 screen / promotion rule

Before any fit, `knowledge/02_preregistered_h31_worming_2026-10-03.md` records the exact scales, continuation/filter definition, spatial folds, draws, model, emission budget, baseline, output metric, and fail-closed gate. The experiment must compare **the same BDE + X1–X3 baseline** to baseline-plus-H31 in each identical fold/draw, using identical training samples and emission settings. Screen draws are 10–11; fresh confirmation draws are 12–13 only if the screen passes. The four spatial quadrants—not fold×draw cells—are the spatial replication units.

Promotion requires a paired mean DTI gain >0.001 on the screen, positive gain in at least 3/4 quadrants, no fold worse than −0.010, no material increase in catalogue-hug share, and the same criteria on fresh confirmation. Comparators must be re-run in the same cells; the predecessor's historical 0.152003389 comparator is not trusted because its own repository records comparator drift. **No TIFF will be created from H31 unless confirmation passes and that exact full-data artifact passes the format audit. No weekly slot is used in this work.**
