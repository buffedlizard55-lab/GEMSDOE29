Multiscale worming survival filter (H52-F, review only - fails the H34 slot bar)

The owner asked for Hornby/Boschetti/Horowitz multiscale worming: edges computed across a sequence of upward-continued versions of the magnetic and gravity grids, with persistence-with-height used as an explicit filter rather than a fixed-scale gradient. This file is that filter, cross-fitted over 8 cells (4 quadrants x draws 20/21) with the frozen control matrix and the frozen emission, minus the pixels flagged WF_SHALLOW_ONLY - edges that vanish at the first continuation step, i.e. the acquisition-artifact class. 38,907 dots; the veto removed 15.5% of the eligible ridge candidates. The audit number behind it: 11.14% of footprint pixels are shallow-only, and the owner-reported best file (D2.8) has 15.26% of its dots in that class with mean survival 0.50530 vs a footprint mean 0.57703, so the winning file sits on low-persistence ground - which is why the veto costs DTI on the catalogue-hidden proxy while helping the off-catalogue SGMC proxy on 4/4 folds. Zero outside the footprint, so a strict whole-array [0,1] check passes (the NaN variant is what the upload form rejected, IR-PORTAL-01).
