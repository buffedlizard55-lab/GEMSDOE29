IR-29-FOOTPRINT-DIFFhighopentraining_features.tif (owner mirror, sha 4371c82e...) has 5,165,852 finite cells vs the sample_submission template's 5,167,373: 3,061 template-footprint cells are nodata inside the features, and 1,540 feature cells lie outside the template footprint. Any pipeline that assumes 'finite in features == finite in template' silently mis-scores/NaNs 3,061 scored pixels.
→ This repo: worming computes on the FEATURES mask; submission emission is masked to the TEMPLATE footprint and every in-footprint pixel is written finite (0.0/1.0), so the difference cannot produce NaN-inside-footprint. Upstream (competition data) needs owner confirmation that both rasters are authentic copies.

IR-29-LINE-PERSISTENCE-INVERSIONmediumopenThe acquisition-line audit (knowledge/01 §2d) predicted E-W striking edges (flight-line aliasing, 200/400 m E-W lines) should be *less* persistent under continuation. Measured on the full grid: mean magnetic persistence by strike is E-W 0.656, Other 0.607, N-S 0.562 — E-W edges are, on average, the MOST persistent. The naive 'E-W = artifact' heuristic is therefore NOT usable as a filter on this grid; regional geology (E-W striking ranges in the Walker Lane transform corridor) plausibly dominates the aliasing signal.
→ Line-suppression (H29-4 notch) remains registered as a future experiment; the persistence filter itself does not encode strike assumptions. See evidence/worming_receipt.json.
IR-29-PARENT-OFF-EDGESmediumopenOnly 2.7% of the live-scored dotted (0.2600) emission dots coincide with p95 level-0 potential-field edges; the parent detector's habitat is mostly terrain/thermal/structural, not geophysical edge maxima. A hard worming GATE therefore has almost no power over the parent emission; only re-ORDERING (or feature-level fusion) can express the hypothesis.
→ Screened both ways (A1 gate, A2 rank, B1 head-features) per knowledge/01; report all three regardless of sign.
